# JavaScript Practice & Data Structures

A collection of my **JavaScript learning exercises, programming practice, data structures implementations, and beginner-friendly projects**. This repository documents my journey in strengthening JavaScript fundamentals and problem-solving skills as a Software Engineering undergraduate.

## 📚 Contents

### 1. JavaScript Practices
A collection of JavaScript exercises and practical examples covering programming fundamentals and small applications.

- To-Do List application.
- JavaScript practice exercises.
- Basic programming concepts.

### 2. JavaScript Array Master Notes
Study notes and examples covering JavaScript array methods and operations, with commented explanations to help understand how they work.

### 3. Data Structures Implementations
Practical implementations of fundamental data structures using JavaScript.

| Data Structure | Description |
|---|---|
| Linked List | Understanding nodes, appending elements, and linked list operations |
| Stack | Implementing the Last In, First Out (LIFO) principle |
| Queue | Implementing the First In, First Out (FIFO) principle |

### 4. HTML & JavaScript Examples
Standalone HTML files demonstrating JavaScript concepts and data structure implementations.

## 🛠️ Technologies Used

- **JavaScript** — programming logic and implementations.
- **HTML5** — structure for browser-based examples.
- **CSS3** — styling where applicable.

## 🚀 Getting Started

No complex setup is required for the current examples.

1. Clone the repository:

   ```bash
   git clone https://github.com/sasindusachintha/JavaScript.git
   ```

2. Open the project folder:

   ```bash
   cd JavaScript
   ```

3. Open an HTML file in your web browser, or open the repository in your preferred code editor.

4. Explore the code, run the examples, and experiment with your own improvements.
